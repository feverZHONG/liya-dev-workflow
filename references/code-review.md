# 预提交代码审查

> 提交前走一遍：安全扫描 + 回归检查 + 独立审查。

## 流程

```
① diff          → git diff --cached
② 安全扫描      → grep 硬编码密钥/shell注入/eval/pickle
③ 回归基线      → stash → 跑测试 → pop → 只计新增失败
④ 自审清单      → 密钥/注入/错误处理/调试代码……
⑤ 独立审查      → delegate_task 给子 agent
⑥ 评估结果      → 全过→提交；有错→修复；两次不过→找用户
```

## 四类审查结果

| 结果 | 含义 | 处理 |
|:----|:-----|:-----|
| SAFE | 不影响行为（未用导入、注释代码） | 自动修 |
| CAREFUL | 改善但不改语义 | 修+验证 |
| RISKY | 可能改行为（API 变更、并发修） | 报用户 |
| BLOCKER | 安全问题、逻辑错误 | 必须修 |
