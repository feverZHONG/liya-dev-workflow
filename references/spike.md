# Spike · 快速验证

> 动手验证想法，不承诺交付。

## 什么时候用

- 「试试这个能不能行」
- 先看下 X 方案是否可行再决定
- 对比 A vs B

## 核心流程

```
拆解 → 研究 → 构建 → 裁决
  ↑______________________↓
       根据发现迭代
```

## 步骤

| 步骤 | 做什么 | 产出 |
|:----|:------|:-----|
| ① 拆解 | 把想法拆成 2-5 个独立问题 | 验证矩阵表 |
| ② 研究 | 调研可行方案，选一个 | 方案对比 |
| ③ 构建 | 写可运行的原型 | `spikes/NNN-name/README.md` |
| ④ 裁决 | VALIDATED / PARTIAL / INVALIDATED | 结论+建议 |
