# 代码清理 · 并行审查

> 四个独立审查员并行跑，找复用/质量/效率/深度问题。

## 什么时候用

用户说了「simplify」「清理代码」「review my changes」的时候。不自动跑。

## 四路并行审查

| 审查员 | 找什么 | 风险等级 |
|:------|:------|:---------|
| ① 复用 | 重复造轮子→指向已有的工具/函数 | SAFE |
| ② 质量 | 冗余状态、参数膨胀、COPY 变体、嵌套过深 | SAFE/CAREFUL |
| ③ 效率 | N+1、重复计算、内存泄漏、静默吞错 | CAREFUL/RISKY |
| ④ 深度 | 补丁打错层了？该修基础设施的修了调用方？ | RISKY |

## 风险处理

| 等级 | 处理 |
|:----|:-----|
| SAFE | 自动应用 |
| CAREFUL | 应用后跑测试验证 |
| RISKY | 报给用户决定 |
